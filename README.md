# Nomie News v2

The news of today from a choice of sources, shown as headlines in the app's colours. Read an article, or write the headline into a note.

Source: https://github.com/RdeLange/nomie-news-v2. Pages: https://dailynomie.github.io/nomie-news-v2/

## Commands

    npm install
    npm test
    npm run build
